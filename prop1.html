1. Introduction & Project Overview

1.1 Purpose

This SRS defines the complete digital architecture for Shakti Sabha — a unified platform reflecting 12 years of genuine on-ground impact, core philosophy, and financial sustainability goals. The platform embodies the "Union of Peace and Revolution" through three pillars: Mardini (Revolution), Shakti Bhava (Peace/Healing), and Shakti Varta (Intellectual Discourse).

1.2 Scope

  • Fully bilingual (Hindi + English) with seamless language switching
  • Secure, fast-loading modules built on Next.js front-end and AWS cloud backend
  • Integrated monetization: LMS, e-commerce, camp bookings, donations, events
  • Zero-knowledge encryption for sensitive counseling and case study data
  • Global talent & volunteer onboarding pipeline

1.3 Core Pillars

MARDINI

The Revolution — self-defense, archival workshops, geographic reach

Shakti Bhava

The Healing Space — counseling, taboo-breaking articles, survivor support

Shakti Varta

Intellectual Discourse — podcasts, seminars, true masculinity (Paurush)

3. Banners & Visual Assets

🖼️ Homepage Banners

  • Hero Banner: Fullscreen video (autoplay muted, loop) with overlay text — "12 Years of Shakti · Union of Peace & Revolution"
  • Pillar Banners: Three distinct visual banners for Mardini, Shakti Bhava, Shakti Varta
  • Impact Banner: Live counters (12 Years, 400+ Schools, Villages reached)
  • CTA Banners: Donate Now, Join Volunteer, Book a Camp

📐 Technical Specifications

  • Desktop: 1920×1080px, 2560×1440px (retina)
  • Mobile: 1080×1920px (vertical), 1200×628px (social)
  • Formats: WebP (optimized), JPEG fallback, MP4 for video
  • Max Size: 200KB per image, 5MB per video (compressed)
  • Accessibility: Alt text for all banners, contrast ratio ≥ 4.5:1
💡 Dynamic Banners: Admin dashboard must allow uploading/replacing banners without code changes. All banners to be responsive and lazy-loaded.

7. Case Study Blog

📝 Anonymized, Taboo-Breaking, Powerful

A secure, anonymized blog platform for sharing real case studies — counseling human trafficking survivors, PTSD, depression, puberty challenges — without compromising identities.

Content Features

  • Rich text editor (headings, quotes, embeds)
  • Category & tag filtering
  • Reading time estimate
  • Related case studies
  • Comments (moderated, anonymous option)

Security & Privacy

  • Zero-Knowledge Database Encryption
  • AES-256-GCM column-level encryption
  • Admin cannot map data to real individuals
  • Consent-based publishing workflow
⚠️ Critical: All case studies must be anonymized. No real names, locations, or identifiable details. Legal review required before publishing.

13. Security & Anonymity Engineering

🔒 Data Protection

  • AES-256-GCM: Column-level encryption for sensitive data
  • Zero-Knowledge Database: Even admins cannot map data to individuals
  • GDPR & IT Act Compliance: Data localization, consent tracking
  • Regular Audits: Quarterly security assessments
  • Incident Response: 24-hour breach notification protocol

🛡️ Platform Security

  • HTTPS/TLS 1.3 encryption in transit
  • DDoS protection (AWS Shield)
  • WAF (Web Application Firewall)
  • Rate limiting & bot protection
  • Two-factor authentication for admin
